# Code of Conduct

This profile repository welcomes respectful and constructive participation.

## Expected behavior
- Be courteous and considerate.
- Provide constructive feedback.
- Respect privacy and differing viewpoints.

## Unacceptable behavior
Harassment, threats, hate speech, personal attacks, spam, or sharing private information without consent are not permitted.

## Scope and enforcement
This policy applies to issues, pull requests, and discussions in this repository. The maintainer may moderate or remove inappropriate contributions.

## Reporting
Please report concerns privately using the contact information at https://codeyantra.in rather than posting sensitive information publicly.
