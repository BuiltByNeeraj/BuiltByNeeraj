# Contributing

Thanks for your interest in improving this GitHub profile.

This repository hosts my public GitHub profile README and community documentation. Suggestions for clarity, accessibility, broken links, and factual corrections are welcome.

## How to contribute
1. Open an issue describing the improvement, or submit a focused pull request.
2. Explain why the change is useful.
3. Preview Markdown and check links.
4. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

Please avoid unrelated promotions and sharing personal information. Contributions are reviewed at the maintainer's discretion.

For individual CodeYantra projects, refer to the contribution guidance in their respective repositories.
