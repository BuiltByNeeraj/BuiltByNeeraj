# Security Policy

## Scope
This repository contains a public GitHub profile README and community documentation. It is not a software product or the security support channel for other CodeYantra projects.

## Reporting
If you discover a security or privacy concern affecting this repository, please **do not disclose sensitive details in a public issue**.

Use the private contact information available at https://codeyantra.in and provide:
- A concise description of the concern
- The affected file or URL
- Reproduction steps, if relevant
- The potential impact

Never include passwords, tokens, or other secrets in your report.

For product vulnerabilities, use that project's own security reporting policy. No fixed response timeline is promised.
